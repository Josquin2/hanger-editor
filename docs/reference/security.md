# Security

The renderer is designed to be used with `v-html` / `dangerouslySetInnerHTML` on
message content.

## Guarantees

- **Text is escaped.** Every source text node, code span, code block, class
  value, and link attribute is HTML-escaped.
- **Unknown links are rejected.** Only configured schemes are allowed. The
  default is `http`, `https`, `mailto`, and `tg`.
- **Unsafe URLs are rendered as labels.** They do not become anchors at all.
- **No HTML input.** The parser accepts markdown, not HTML. `<img onerror=…>`
  is text after parsing and is escaped when rendered.
- **Fixed attributes.** Links get `target="_blank"` and
  `rel="noopener noreferrer nofollow"` by default; both can be overridden.

The URL check rejects:

- schemes outside the allow-list;
- ASCII control characters and whitespace anywhere in the URL;
- backslashes;
- protocol-relative URLs (`//host/...`).

```ts
import { sanitizeUrl } from 'hanger-editor'

sanitizeUrl('javascript:alert(1)') // null
sanitizeUrl('data:text/html,hi') // null
sanitizeUrl('https://example.com/a_(b)') // allowed
sanitizeUrl('/channels/1', { allowRelativeLinks: true }) // allowed
```

## Rendering

```ts
const html = renderHtml(parseMessage(message.content))
element.innerHTML = html
```

This is safe because the only HTML in `html` was generated by the renderer and
every user-controlled value was escaped. Do not append or interpolate other
untrusted HTML into the same element.

## Custom schemes

```ts
renderHtml(document, {
  allowedSchemes: ['https', 'my-app'],
})
```

Only extend the allow-list when the application understands the scheme. Adding
`javascript` or `data` effectively disables link safety.

## Rich textarea

The rich textarea is a visual layer, not a security boundary. It displays the
markdown source in a textarea; the value sent to the server is still plain
markdown. Rendering a received message still goes through `renderHtml`.

The overlay is built only from parsed source ranges, and all text is escaped by
the source renderer. Do not feed custom HTML into the overlay.
