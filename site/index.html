Telegram-style formatting for a plain textarea.

01

Mount the editor

The editor owns the textarea value, formatting commands, validation and submit payload. A native textarea stays in place, so IME, accessibility and mobile selection keep working. Pick a binding:

Nuxt: use the Vue composable with a template ref and, optionally, v-model. The composable attaches on mount and renders validation state during SSR. Keep toolbar buttons on @mousedown.prevent so they do not steal the selection.

03

Validation that blocks noise

Validation runs on visible text, not raw markdown. Whitespace, zero-width characters, bidi controls and BOMs are stripped before the empty check. The default limit is 4096 UTF-16 code units; code-point length is not the same thing on emoji.

  • EMPTY_MESSAGE — nothing visible remains.
  • TOO_LONG — visible text exceeds the limit.
  • Markers are free: **hello** has length 5.
  • allowEmpty and submit({ force: true }) are there for attachment-only messages.

04

Render the stored message

Store the raw markdown. Parse and render it where messages are shown. The renderer escapes every text node and attribute, and only emits links whose schemes are on the allow-list.

Use a block container, not a <span>: quotes and code blocks are block elements. Pass { wrapParagraphs: true } if you prefer semantic <p> wrappers over the chat-friendly <br> fragment.

06

Security model

  • HTML is never accepted as input; text is escaped on the way out.
  • Default link schemes are http, https, mailto and tg.
  • Control characters, whitespace, backslashes and protocol-relative URLs are rejected.
  • Unsafe links render as their label, without an anchor.
  • If you extend allowedSchemes, that is your trust decision.

Rules worth knowing

  • Markers must touch non-whitespace: ** bold ** stays literal.
  • snake_case_name is safe; underscores do not format inside words.
  • ***both*** means bold + italic.
  • Code spans and fenced blocks are opaque: markup inside is literal.
  • Links may format their label but cannot contain another link.
  • No headings, lists, tables, images or bare-URL autolinking.

Security

Safe to pass to v-html.

The library never trusts message input as HTML. It parses markdown into a typed tree, escapes every text node and attribute, and validates every URL before rendering it.

Escaped by construction

Text and attributes go through HTML escaping. There is no template interpolation of untrusted strings.

URL allow-list

Only http, https, mailto and tg by default. javascript:, data: and protocol-relative URLs never become anchors.

No raw HTML

Input like <img onerror=…> is escaped text, not markup. Code blocks are escaped as code.

No upload, no network

Parsing, validation and rendering are synchronous and local. The library never sends or fetches a message.
